# BOJ 2133 - 타일 채우기

## 문제

- 링크: https://www.acmicpc.net/problem/2133
- 태그: 다이나믹 프로그래밍

## 접근 방식

3×N을 2×1, 1×2 타일로 채우는 경우의 수. 우선 N이 **홀수**면 답은 0 (총 칸 수 3N이 홀수이므로 2칸 타일로 채울 수 없음).

### 풀이 1: "꽉 찬 직전 단면"으로 분해 — `dp[n]` 1차원

3×n에서 가장 오른쪽이 처음으로 "수직 단면이 꽉 차는" 위치 i를 기준으로 분해. 그 i 이후 구간(폭 n−i)은 **단면 없이 한 덩어리로 채워지는 형태**.

- 폭 2짜리 기본 채움: 그림으로 확인 가능한 **3가지** (가로2 × 3 / 세로2 두 개를 위·아래로 배치하는 두 형태 등)
- 폭 4 이상의 "단면이 한 번도 갈리지 않는" 채움: 폭 4, 6, 8, ... 각각 **2가지씩** 존재 (위/아래 거울)

따라서 점화식:

```
dp[0] = 1
dp[n] = 3 * dp[n-2] + 2 * dp[n-4] + 2 * dp[n-6] + ... + 2 * dp[0]   (n 짝수)
dp[n] = 0   (n 홀수)
```

### 풀이 2: "직전 열의 채움 상태"를 차원으로 추가 — `dp[n][k]`

오른쪽 끝 열의 채움 패턴을 상태 `k`로 들고 가는 표준 비트 DP의 단순화 버전. 이 풀이에서는 상태를 3개로 잡음 (`k ∈ {0, 1, 2}`):

- `k = 0`: 윗칸이 채워지고 가운데/아랫칸이 비어 있어 다음 열로 짝맞춤이 넘어가는 형태
- `k = 1`: 가운데가 비고 양 옆이 채워진 형태 (또는 그 거울)
- `k = 2`: 열이 **완전히 꽉 찬** 형태 → 답에 해당

상태 간 전이를 손으로 엄밀히 따져 점화식을 짠 풀이.

## 풀이

### Solution 1-1 — Bottom-Up (1차원 dp)

```python
import sys

input = sys.stdin.readline

N = int(input())

dp = [0] * 31
dp[0] = 1

for n in range(2, 31, 2):
    dp[n] = 3 * dp[n - 2]
    for i in range(n - 4, -1, -2):
        dp[n] += 2 * dp[i]

print(dp[N])
```

- 짝수 n만 채움 (홀수는 자동으로 0)
- N ≤ 30이라 미리 30까지 다 계산해두는 방식

### Solution 1-2 — Top-Down (메모이제이션)

```python
def func(n):

    if n % 2 == 1:
        return 0

    if dp[n] != -1:
        return dp[n]

    dp[n] = 3 * func(n - 2)

    for i in range(n - 4, -1, -2):
        dp[n] += 2 * func(i)

    return dp[n]


N = int(input())

dp = [-1] * 31
dp[0] = 1

print(func(N))
```

- 같은 점화식의 재귀 + 메모 버전
- 홀수에서 0을 즉시 반환하는 base case

### Solution 2-1 — Bottom-Up (2차원 dp[n][k])

```python
N = int(input())

dp = [[0] * 3 for _ in range(31)]
dp[1][1] = 2
dp[2][0] = 2
dp[2][2] = 3

for n in range(3, 31):
    dp[n][0] = dp[n - 1][1]
    dp[n][1] = 2 * dp[n - 1][2] + dp[n - 1][0]
    dp[n][2] = dp[n][0] + dp[n - 2][2]

print(dp[N][2])
```

- 마지막 열의 채움 상태 `k`를 추가 차원으로 들고 가 점화식을 깔끔히 분리
- 정답은 마지막 열까지 **꽉 찬** 상태인 `dp[N][2]`

### Solution 2-2 — Top-Down (메모이제이션, 2차원)

```python
def func(n, k):

    if n <= 0:
        return 0
    if dp[n][k] != -1:
        return dp[n][k]

    if k == 0:
        dp[n][k] = func(n - 1, 1)
    if k == 1:
        dp[n][1] = 2 * func(n - 1, 2) + func(n - 1, 0)
    if k == 2:
        dp[n][2] = func(n, 0) + func(n - 2, 2)

    return dp[n][k]


N = int(input())

dp = [[-1] * 3 for _ in range(31)]
dp[1][1] = 2
dp[2][0] = 2
dp[2][2] = 3

print(func(N, 2))
```

- 2차원 점화식의 재귀 버전
- base 값은 직접 채워두고 (`dp[1][1]`, `dp[2][0]`, `dp[2][2]`) 그 외는 재귀로 채움

## 복잡도

|              | 시간    | 공간  |
| ------------ | ------- | ----- |
| Solution 1-1 | O(N²)   | O(N)  |
| Solution 1-2 | O(N²)   | O(N)  |
| Solution 2-1 | O(N)    | O(N)  |
| Solution 2-2 | O(N)    | O(N)  |

- N ≤ 30이라 어느 풀이든 즉시 끝남

## 배운 점

- "타일링 + 단면" 류 문제는 **마지막에 단면이 갈리는 위치를 기준으로 분해**하면 1차원 DP가 자연스럽게 도출됨
- "기본 채움 3가지 + 추가 채움 2가지/짝수 폭"은 직접 그림을 그려보면 빠르게 보임 → 점화식의 계수 3, 2가 그림에서 떨어짐
- 같은 문제를 **상태 차원을 더해 O(N)** 으로 줄일 수 있음 (단면 상태를 변수화). 일반화하면 비트마스크 DP의 축소판
- N이 홀수면 답이 0 → 점화식 시작 전에 명시적으로 끊어주면 코드와 사고가 모두 단순해짐
