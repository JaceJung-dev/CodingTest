# BOJ 10870 - 피보나치 수 5

## 문제

- 링크: https://www.acmicpc.net/problem/10870
- 태그: 재귀, 수학, 다이나믹 프로그래밍

## 접근 방식

피보나치 수를 구하는 4가지 방법을 비교 구현:

1. **반복문 (변수 스왑)** - `fibo1`: 두 변수만 사용해 순차적으로 계산
2. **반복문 (배열)** - `fibo2`: 배열에 값을 저장하며 bottom-up 계산
3. **순수 재귀** - `fibo3`: 기본적인 재귀 호출 (중복 계산 발생)
4. **메모이제이션 재귀** - `fibo4`: 전역 배열에 캐싱하여 중복 계산 제거

## 풀이

| 함수       | 방식              | 핵심                           |
| ---------- | ----------------- | ------------------------------ |
| `fibo1(n)` | 반복 + 변수 스왑  | `a, b = b, a + b`              |
| `fibo2(n)` | 반복 + 배열       | `arr[i] = arr[i-1] + arr[i-2]` |
| `fibo3(n)` | 순수 재귀         | base case: n=0→0, n=1→1        |
| `fibo4(n)` | 메모이제이션 재귀 | `arr[n] != -1`이면 캐시 반환   |

각 방식의 실행 시간을 `elapsed_time` context manager로 측정하여 비교할 수 있도록 구성함.

## 복잡도

| 함수    | 시간 복잡도 | 공간 복잡도   |
| ------- | ----------- | ------------- |
| `fibo1` | O(n)        | O(1)          |
| `fibo2` | O(n)        | O(n)          |
| `fibo3` | O(2^n)      | O(n) (콜스택) |
| `fibo4` | O(n)        | O(n)          |

## 배운 점

- 순수 재귀(`fibo3`)는 중복 호출로 인해 지수적 시간이 걸리지만, 메모이제이션(`fibo4`)을 적용하면 O(n)으로 개선됨
